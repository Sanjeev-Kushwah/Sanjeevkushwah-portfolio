# Sanjeev Kushwah — Developer Portfolio

![Sanjeev Kushwah Portfolio](https://sanjeevkushwah.dev/android-chrome-512x512.png)

Official professional developer portfolio of **Sanjeev Kushwah** — Backend Java & Spring Boot Developer. Built with React 18, Vite, Tailwind CSS, and React Router.

## 🚀 Key Highlights & Features

- **Modern Architecture**: Fast SPA with React Router multi-page navigation (`/about`, `/skills`, `/experience`, `/projects`, `/education`, `/contact`).
- **Circular Reveal Theme Transition**: Hardware-accelerated radial reveal dark/light mode transition using View Transitions API.
- **Custom SK Monogram Favicon Suite**: Vector & PNG favicon suite optimized for desktop and mobile PWA standards.
- **SEO & Social Cards**: Fully configured Open Graph and Twitter Card metadata for rich social sharing previews.
- **Responsive & Recruiter-Friendly Layout**: Top-aligned, compact hero section designed for immediate impact on desktop and mobile viewports.

## 🛠️ Tech Stack

- **Frontend**: React 18, React Router v6, Tailwind CSS, Lucide Icons
- **Backend / Core Competencies**: Java 8+, Spring Boot, Spring Data JPA, Hibernate, RESTful APIs, MySQL, Maven, Postman
- **Build Tool**: Vite

## ⚡ Quick Start

```bash
# Clone the repository
git clone https://github.com/Sanjeev-Kushwah/sanjeev-kushwah-portfolio.git

# Navigate to project directory
cd sanjeev-kushwah-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

## 📦 Build for Production

```bash
# Generate optimized production build
npm run build

# Preview production build locally
npm run preview
```
